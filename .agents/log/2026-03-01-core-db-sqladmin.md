# Ядро системи: PostgreSQL та SQLAdmin

Статус: done

## Рішення
Основою всієї системи є реляційна база даних PostgreSQL.
Ключові домени та сутності, що зберігаються в БД:
- **Будинки (Houses)**
- **Квартири (Apartments)**
- **Користувачі/Мешканці (Users)**
- **Запити на пропуск гостей (Guest Passes / Requests)**

Для керування цими даними (CRUD операції) використовується бібліотека **SQLAdmin**, яка інтегрована безпосередньо з FastAPI застосунком. Вона надає зручний веб-інтерфейс (адмін-панель) для перегляду, створення, редагування та видалення записів (наприклад, для роботи адміністратора або охорони).

## Чому
- **PostgreSQL:** Забезпечує надійність, цілісність даних та строгі зв'язки (Foreign Keys) між сутностями (наприклад, мешканець належить до певної квартири, квартира — до будинку, а заявка на пропуск формується конкретним мешканцем).
- **SQLAdmin:** Дозволяє отримати готову, повноцінну адмін-панель "з коробки" для SQLAlchemy моделей. Це суттєво економить час на розробку кастомного фронтенду для стандартних операцій керування даними бек-офісу.

## Зачеплені файли/модулі
- **DB та Моделі:** `backend/src/models/` (визначення SQLAlchemy моделей).
- **Міграції:** `backend/src/alembic/` (керування схемою бази даних).
- **Адмін-панель:** `backend/src/admin/` (або відповідний файл/модуль, де налаштовуються Views для SQLAdmin).
