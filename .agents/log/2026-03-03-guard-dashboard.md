# Дашборд Охорони (Guard Dashboard) та Автологін

Статус: done

## Рішення
Для співробітників служби охорони розроблено окремий веб-інтерфейс — **Guard Dashboard**, написаний на фреймворку **Vue.js**.
Доступ до дашборду суворо обмежений: увійти можуть лише користувачі з правами охоронця (guard) або адміністратора (admin) за допомогою логіна та пароля.

**Спеціальна фіча — Автологін:**
Щоб спростити процес авторизації для охорони та зменшити кількість помилок при введенні паролів на мобільних пристроях, реалізовано механізм автологіну:
- Коли створюється нова заявка (на пропуск чи парковку), бот надсилає охоронцю повідомлення в Telegram.
- До повідомлення прикріплена спеціальна кнопка (Inline Keyboard).
- При натисканні на цю кнопку дашборд відкривається безпосередньо як **Telegram WebApp** у внутрішньому браузері Telegram.
- Під час завантаження сторінки логіну відбувається перевірка наявності `window.Telegram.WebApp.initData`.
- Цей криптографічно підписаний рядок (`initData`) автоматично відправляється на бекенд (ендпоінт `/api/auth/telegram-webapp`), де він валідується за допомогою токена бота.
- Якщо валідація успішна — бекенд повертає стандартний JWT токен доступу (`access_token`), і охоронець миттєво авторизується в системі без ручного введення логіна та пароля.

## Чому
- **Vue.js:** Дозволяє створити швидкий, реактивний та зручний інтерфейс для оперативної роботи охорони.
- **Обмеження доступу:** Захищає конфіденційні дані мешканців від несанкціонованого доступу.
- **Автологін через Telegram WebApp:** Є критично важливим UX-покращенням. Охоронцям незручно постійно перелогінюватись, особливо під час інтенсивного потоку гостей. Використання нативного `initData` від Telegram забезпечує високий рівень безпеки без необхідності генерувати та передавати одноразові токени через URL, економить час та виключає помилки вводу (typos).

## Зачеплені файли/модулі
- **Frontend (Vue):** 
  - `frontend/src/views/Login.vue` (компонент, що перевіряє `tg.initData` під час завантаження `onMounted` та викликає логіку входу).
  - `frontend/src/store/auth.js` (Pinia store з дією `loginViaTelegram`, що виконує POST-запит до API).
- **Backend:** Ендпоінт `/api/auth/telegram-webapp` для криптографічної валідації `init_data` від Telegram та видачі JWT (`access_token`).
- **Telegram Bot:** Формування сповіщень з Inline Keyboard кнопкою типу `web_app`, яка містить URL дашборду.
